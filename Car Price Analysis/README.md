Car Price Analysis (EDA Project)
📌 Project Overview

This project is an Exploratory Data Analysis (EDA) on a car dataset to understand how different factors like brand, fuel type, engine size, mileage, and condition affect car prices.

The goal is to extract meaningful insights using Python data analysis and visualization libraries.

📊 Dataset Features

The dataset contains the following columns:

Car ID
Brand
Model
Year
Engine Size
Fuel Type
Transmission
Mileage
Condition
Price

Python

NumPy 
Matplotlib 
Seaborn

🔥 Key Insights
Premium brands have significantly higher average prices.
Mileage has a negative impact on car price.
Engine size is positively related to price.
Some brands show very high price variation (luxury + economy mix).
Fuel type also affects pricing and mileage efficiency.
